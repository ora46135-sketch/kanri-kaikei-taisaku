Lecture 01

財務会計と管理会計の違いを説明せよ。

情報利用者利用目的会計原則過去志向／未来志向要約／詳細

Model Answer

財務会計は、株主や債権者など企業外部の利害関係者に、財政状態と経営成績を報告するための会計である。一般に認められた会計原則に従い、過去の実績を四半期または1年単位で、主に企業全体の要約として報告する。一方、管理会計は、企業内部のマネジャーが現状把握・意思決定・動機づけに使うための会計である。作成上の制約はなく、未来志向で、期間も柔軟に決められ、部門別・製品別の詳細な情報を扱う。したがって両者の違いの根本は「誰が、何のために使うか」にあり、そこから制約・時間・報告書の形の違いが生まれると考える。

Lecture 01

マネジメントコントロールとは何か。効果的であるための要件を2つ挙げて説明せよ。

上位→下位のマネジャー戦略の実行Goal congruenceCost-benefit balance計画→実行→評価→是正

Model Answer

マネジメントコントロールとは、組織の戦略を実行するために、上位のマネジャーが下位のマネジャーに影響を与えるプロセスである（Anthony and Govindarajan, 2007）。管理会計はその中核技法であり、計画→実行→評価→是正のサイクルの中で、予算や業績報告書として使われる。必要になる背景には、外部要因のほか、個人が何をすべきかわからない、分権化した組織で共通の目的が理解されていない、という内部の問題がある。効果的であるための要件は2つある。①Goal congruence（目標一致性）：メンバーが組織の目標達成に向けて正しい行動をとるよう動機づけられていることである。②Cost-benefit balance：仕組みから見込まれる便益が、かかるコストを上回っていることである。

Lecture 04

責任センターとは何か。4つの種類と、設定するときの注意点を説明せよ。

責任変数収益・コスト・プロフィット・投資典型例管理可能性唯一絶対はない

Model Answer

責任センターとは、売上・費用・利益・投資などの会計数値が、マネジャーの責任変数に含まれている組織単位である。責任変数の違いで4種類に分かれる。収益センターは売上を責任変数とし、典型例は営業部門である。コストセンターは費用を責任変数とし、典型例は生産部門・研究開発部門である。プロフィットセンターは利益を責任変数とし、典型例は事業部である。投資センターは利益と投下資本の両方を責任変数とし、典型例は子会社やカンパニーである。設定の注意点は2つある。①組織と責任変数の組み合わせは自由で、唯一絶対はない。②マネジャーが影響を及ぼせる（管理可能な）項目を責任変数にする。管理できない数字で評価されると、モチベーションや行動に悪影響が出るためである。

Lecture 04

工学的コストセンターと裁量的コストセンターの違いと、それぞれの評価方法を説明せよ。

インプットとアウトプットの対応標準原価標準原価差異費用予算との差異

Model Answer

両者はインプットとアウトプットの対応関係の違いで分けられる。工学的コストセンターは、製造原価のように、アウトプットに必要な金額をそれなりの信頼性で推定できる部門であり、典型例は生産部門である。評価は、実際のコストを標準原価と比べて行う。標準原価差異（標準原価－実際の製造原価）がプラスなら、原価を低く抑えられたことになる。裁量的コストセンターは、必要な金額を工学的に見積もるのが難しい部門であり、典型例は研究開発部門や本社間接部門である。評価は実際の費用と費用予算の差異で行う。ただしアウトプットを数値で評価しにくいため、予算内に収まっていても効率的とは限らない。

Lecture 04

プロフィットセンターのメリットとデメリットを挙げ、デメリットへの対策を述べよ。

利益への意識経営能力の育成近視眼的行動振替価格BSC

Model Answer

メリットは2つある。①マネジャーがインプットとアウトプットのバランスを意識し、利益への意識が上がる。②事業部長が経営全般を見られるマネジャーに育つ場になる。デメリットも2つある。①近視眼的行動である。当期の利益のために研究開発・研修・メンテナンスなどの費用を削る。在任期間が短ければ、その悪影響を受けずに済んでしまう。②社内のコンフリクトである。部門が多いほど振替価格が増え、利益に直接響くため利害が対立しやすい。対策として、①にはBSC（Balanced Scorecard）がある。財務だけでなく顧客・社内ビジネスプロセス・学習と成長の視点でも評価し、将来の利益の元を削る行動を抑える。②の振替価格は、市価があれば市価を使うのが望ましいとされる。

Lecture 05

投資センターの評価方法と、メリット・デメリットを説明せよ。投下資本の考え方にも触れること。

貸借対照表項目投下資本利益率運転資本＋固定資産現金を除く資本効率

Model Answer

投資センターは、利益と、利益を獲得するのに使用した資産の両方を責任変数に含む組織であり、典型例は子会社や独立性の高いカンパニーである。損益計算書の項目だけでなく、売上債権・棚卸資産・設備などの貸借対照表の項目にも責任を持つ。評価は、投下資本利益率（利益÷投下資本）の実績値と目標値を比べて行う。投下資本は運転資本（棚卸資産＋売上債権－仕入債務）と固定資産の合計で考え、本社が管理していることが多い現金は除く。メリットは、利益だけでなく投下資本にも注意を払い、経営陣と同じように資本効率を意識するマネジャーが育つ点である。デメリットは基本的にプロフィットセンターと同じで、加えて分母の投下資本を小さく見せる行動をとるおそれがある。

Lecture 05

共通固定費をマネジャーの評価から除く理由と、それでも配賦する目的を説明せよ。

本社系部門管理可能性管理可能利益／営業利益全社の業績配賦基準

Model Answer

共通固定費は、人事部や財務経理など本社系部門の費用である。事業部のマネジャーはこの費用を動かせないため、評価に含めると管理可能性の考え方に反する。そのため、マネジャーの業績評価には管理可能（貢献）利益を使い、事業の事業性評価には営業利益を使い、共通固定費はどちらからも除くのが鉄則である。それでも配賦する目的は、事業部だけでなく全社の業績を、事業部と本社の両方に意識させるためである。配賦するときは、売上高・投下資本・社員数などの合理的な配賦基準を使う。

Case · Lec 04

カルビーの国内事業と海外事業の業績指標はどのようなものか。なぜそのような指標を設定しているか。

国内＝EBITDAマージンの最大化海外＝EBITDA成長の最大化事業の段階管理できる範囲

Model Answer

カルビーは、国内コア事業では「EBITDAマージンの最大化」、海外事業では「EBITDA成長の最大化」を掲げている。中期の目標として、国内は売上高の年平均成長率6%以上・EBITDAの年平均成長率10%以上、海外は売上高10%以上・EBITDA15%以上を置いている。理由は2つあると考える。①国内は原料から営業まで本社が一体で管理でき、市場も成熟しているため、規模より稼ぐ効率（マージン）を高めることが課題になる。②海外は成長投資の段階にあり、まず売上と稼ぐ力の規模を伸ばすことが優先される。したがって、事業の段階とマネジャーが管理できる範囲に合わせて、指標を分けていると考える。

①②の理由は第03回事前課題の下書き（自分の考え）による。授業での解説はノートに記録がない。数値は第03回の配布資料（p.2・p.8・p.17）にもとづく。

Case · Lec 05

業績目標としてEBITDAを用いることの課題を挙げよ。また、カルビーがROICを重要な業績目標として掲げる理由を述べよ。

減価償却費を足し戻す投資の負担が見えない資本効率WACCとの比較ROE・企業価値

Model Answer

EBITDAは、一般に営業利益に減価償却費を足し戻した指標である。課題は2つあると考える。①設備投資の負担（減価償却費）が数字に出ないため、投資を増やしても指標が悪化しにくく、過大な投資を招くおそれがある。②投下資本の大きさを見ないため、元手に対してどれだけ効率よく稼いだか（資本効率）がわからない。これに対してROICは、利益を投下資本で割った指標であり、資本効率を測れる。さらにWACC（資本コスト）と比べることで、株主や債権者が求める水準以上に稼いでいるかを判断できる。カルビーの図でも、EBITDA成長→ROIC－WACCスプレッドの最大化→ROE→企業価値向上とつながっている。したがって、EBITDAで稼ぐ力を伸ばしつつ、ROICで投資に規律をかけるために、ROICを重要な目標に掲げていると考える。

課題①②とまとめは自分の考え（第05回の授業の解説はノートに未記入）。カルビーの図は第04回の投影スライドによる。

カルビーは単一市場型・関連多角型・非関連多角型のどれに当てはまるか。理由とともに述べよ。

授業の問い：①ほかの事業に応用・共通利用できる技術、設備、生産、マーケティング、流通、ロジスティクスのノウハウがあるか。②M&Aや買収で拡大する考え方や必要性があるか。

How to Write

この問いは講義ノートに授業の結論が記録されていないため、解答例は作っていない。書くときは、①定義（3類型のうちどれか）→②授業の問い①②に沿ったカルビーの事実→③「したがって〜型だと考える」の順にまとめる。迷ったら、チャットで一緒に答え合わせをする。
